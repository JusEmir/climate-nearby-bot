# Climate Nearby Bot

Telegram-бот на тему глобального потепления для экологов, жителей и волонтёров.

## Цель

Помогать пользователям находить экологические советы с учётом местоположения, сообщать о локальных проблемах и планировать экоактивности.

## Планируемые функции

- `/start` — приветствие и описание возможностей.
- `/help` — справка по командам.
- Геолокация — выбор региона и получение соответствующих советов.
- Локальный прототип базы экомаршрутов и экологических событий.
- Сообщения о мусоре, загрязнении воздуха или опасных явлениях.
- Проверяемые климатические советы без медицинских обещаний.

## Стек

- Python 3.10+
- python-telegram-bot
- python-dotenv
- FastAPI
- Uvicorn

## Зависимости

```text
python-telegram-bot==21.10
python-dotenv==1.0.1
fastapi==0.115.6
uvicorn==0.34.0
```

## Быстрый запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
python bot.py
```

В `.env` укажите:

```text
TELEGRAM_BOT_TOKEN=ваш_токен
```

## Текущее задание

Создать каркас бота с командами `/start` и `/help`, добавить запуск из консоли и краткую документацию.

Критерии готовности:

- бот запускается локально;
- `/start` отправляет приветственное сообщение;
- `/help` отображает доступные команды;
- в README описаны установка и запуск;
- секреты Telegram не добавлены в репозиторий.
